ข้อ 1: ฟังก์ชันคำนวณคะแนน
ข้อแรกคือการแยกหน้าที่คำนวณคะแนน
ตัวเช็กคะแนนถูกต้อง: เริ่มจากทำตัวตรวจก่อนเลยว่า ค่าที่ส่งเข้ามาเป็นตัวเลขจริงๆ ไหม แล้วอยู่ในช่วง 0 ถึง 100 หรือเปล่า เอาไว้ใช้เป็นเกราะป้องกันด่านแรก
ตัวตัดเกรด: โจทย์ไม่อยากให้เขียน if-else ซ้อนกันหลายๆ ชั้น เพราะโค้ดจะดูรกมาก เลยใช้แนวคิด 'สร้างตารางเกณฑ์คะแนนไว้เป็นคู่ๆ' แล้วสั่งให้โปรแกรมวิ่งหาเกณฑ์แรกที่คะแนนผ่าน พอเจอเกณฑ์ไหนปุ๊บก็ดึงเกรดนั้นออกมาตอบเลย ทำให้โค้ดสั้นและดูเป็นระเบียบขึ้นเยอะ
เรื่องคะแนน Workshop และ Default Parameter: มีการตั้งค่าเริ่มต้นเอาไว้ว่า ถ้าไม่ระบุคะแนนเต็ม ให้คิดที่ 60 และถ้าไม่ระบุน้ำหนัก ให้คิดที่ 20
ตอนลองส่งคะแนนแค่ดิบ 48 กับส่งครบ 3 ค่า: ได้ผลลัพธ์เท่ากันเลย เพราะถ้าไม่ส่งค่าพารามิเตอร์ตัวหลังๆ ตัว JavaScript จะแอบหยิบค่าเริ่มต้นที่ตั้งไว้มาคิดให้เองโดยอัตโนมัติ
ตอนลองส่ง undefined ไว้ตรงกลาง: ได้ผลลัพธ์เหมือนเดิม เพราะคำว่า undefined เป็นการส่งสัญญาณบอกระบบว่า 'ตรงนี้ขอเว้นไว้นะ ให้ไปหยิบค่าเริ่มต้นมาใช้แทน' ส่วนตัวหลังสุดที่ส่งตัวเลขใหม่เข้าไป มันก็จะเปลี่ยนไปใช้เลขใหม่ตามที่สั่ง
